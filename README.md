# Rosie OS · Etapa 2

Site fictício interativo da Rosie Café, com estética de desktop corporativo inspirada no Windows XP, visual rosé e segredos escondidos em documentos e no terminal.

## Arquivos
- `index.html`: estrutura da interface.
- `style.css`: tema, janelas, barra de tarefas e adaptação para celular.
- `script.js`: interação, terminal, arquivos, mensagens e pistas.

## Publicar no GitHub Pages pelo celular
1. Extraia o ZIP no celular.
2. No GitHub, crie um repositório público, por exemplo `rosie-os`.
3. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório. Não envie apenas a pasta que contém os arquivos.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
7. Aguarde a publicação e abra o endereço mostrado pelo GitHub Pages.

## Testar localmente
Abra `index.html` em um navegador moderno. Para melhor compatibilidade, publique pelo GitHub Pages.

## Comandos do terminal
`help`, `whoami`, `date`, `status`, `files`, `read <arquivo>`, `open files`, `open mail`, `open notepad`, `clear`.

Alguns comandos de exploração (`system32`, `rosie_core`, `override`) revelam pistas narrativas. O sistema é uma experiência fictícia executada no navegador; não autentica usuários reais nem envia dados para um servidor.
